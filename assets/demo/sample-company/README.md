# Quillfield Software (fictional)

> Fictional sample company for the grcskills demo. Every name, number and record in this folder is invented. People appear only by role.

Quillfield Software is a 42-person B2B SaaS company that reconciles supplier invoices for mid-size retailers in the EU and the UK. Production runs on one cloud provider in an EU region. Engineering is 18 people; there is no full-time security or compliance hire.

## Where we are

- Sales keeps losing time on customer security questionnaires. Two enterprise prospects asked for ISO 27001 certification.
- The CTO wants a certification audit within six months. Nobody has run an internal audit yet.
- The policy set was written two years ago from a template and has not been reviewed since.
- An AI feature that drafts dispute emails with a third-party model API shipped last quarter.

## Folders

- `policies/`: the current policy set
- `registers/`: risk register, asset inventory, vendor list, statement of applicability
- `incidents/`: incident log
- `evidence/`: what we have collected so far
